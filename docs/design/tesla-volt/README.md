# TESLA VOLT — визуальные макеты

Премиальные PNG-макеты сайта компании **Tesla Volt**. Это только визуальная концепция: без вёрстки продукта и без реализации в Next.js.

Визуальный язык: тихая технологическая роскошь, архитектура, чистая энергия, Smart Home. Не строительный корпоратив и не cyberpunk.

## Айдентика

Файл [`00-logo.png`](./00-logo.png) — самостоятельный знак Tesla Volt: тонкая золотая окружность, солнечная дуга и напряжение, сходящееся в V. Это не логотип Tesla Motors.

Палитра:

- графит `#0B0C0E`
- тёплый белый `#F4F1EA`
- приглушённое золото `#C4A35A`
- металлические линии и стекло

Типографика в макетах: Manrope.

Контактные данные на экранах — концептуальные, для композиции.
